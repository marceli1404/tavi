# Tavi Studio Edition / preview

A standalone creative design and animation playground built with the `tavi-web-design` skill's principles. It includes five live visual modes, keyboard-accessible command palette (Ctrl/Cmd+K), motion lab, responsive work gallery, generative Canvas art and a working brief generator.

Run locally: open `index.html` or run `python -m http.server 8080` from this folder.

Deployment preview: https://test.marceli.tech (Cloudflare Worker custom domain). Not the production Tavi application. Test site has `noindex` metadata.

No build step or runtime dependencies, other than optional Google Fonts. Fictional creative-work examples are explicitly labelled. Respect reduced motion and use the Calm/Alive/Off controls.
