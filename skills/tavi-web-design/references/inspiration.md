# Reference library: study behaviors, not screenshots

The 100-site discussion combines award-winning experimental pages and strong real-world product websites. It was an editorial curation, not a ranked performance audit. Never reproduce award status as a fact without confirming the relevant award/year, and never assume a live page is unchanged.

## How to use reference examples
1. For each inspiration site note its **audience, primary action, type scale, spacing, imagery, interaction and accessibility tradeoffs**.
2. Extract a *principle* (e.g. "product proof above the fold") instead of copying DOM/CSS/branding.
3. Compare relevant production sites alongside experimental award work. A campaign's splash effect is rarely appropriate for task-heavy dashboards.
4. Make the resulting design visibly original and justified by the new client's context.
5. If claiming official awards, verify first-party awards lists with dates; avoid derivative marketing claims.
